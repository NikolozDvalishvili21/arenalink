## პროექტის აღწერა

ArenaLink არის ქართული ესპორტის ტურნირების პლატფორმა ლოკალური ორგანიზატორებისთვის, გუნდებისთვის და მაყურებლისთვის. დღეს ასეთი ტურნირები Discord-ისა და Facebook-ის მეშვეობით ტარდება: ცხრილები ხელით იხატება, ანგარიშსწორება პირადი გადარიცხვით ხდება, შედეგები ფოტოების სახით მოდის, ამიტომ ორგანიზატორს დრო მიაქვს, მოთამაშეებს კი სამართლიანობაში ეჭვი ეპარებათ. ArenaLink ამ პრობლემებს ეხმიანება: ორგანიზატორი ქმნის ტურნირს, გუნდები რეგისტრირდებიან და ონლაინ იხდიან, სისტემა თავად აგებს ცხრილებს და ამოწმებს შედეგებს, მაყურებელი კი ცხრილს ლაივში ხედავს. პლატფორმა თამაშისგან დამოუკიდებელია (FIFA, CS2, Dota 2), ხოლო MVP ერთ ფორმატს მოიცავს: single elimination.

## Stakeholder-ები

**მოთამაშე** ყველაზე ხშირი მომხმარებელია. მისი ინტერესია, რომ რეგისტრაცია მარტივი იყოს, ცხრილი ყველასთვის ჩანდეს და შედეგი სწრაფად დადასტურდეს. თანხას თავად იხდის. ვეტოს უფლება არ აქვს, მაგრამ შედეგი შეიძლება გაასაჩივროს (მატჩი ხდება „სადავო“).

**ორგანიზატორი** ტურნირს ქმნის და მართავს. მისთვის მთავარია, ხელით მუშაობა შემცირდეს და გადახდებზე სრული სურათი ჰქონდეს. პლატფორმა შესატანიდან საკომისიოს იღებს, ამიტომ ორგანიზატორი ფაქტობრივად მთავარი მომხმარებელია. სადავო შედეგზე საბოლოო გადაწყვეტილებას ის იღებს და შეუძლია გუნდის შედეგი გააუქმოს

**მაყურებელი** შედეგებს უყურებს და არაფერს იხდის. მთავარი მოთხოვნა ისაა, რომ შედეგების ნახვა შეძლოს უპრობლემოდ და ინფორმაცია სწრაფად განახლდეს. გავლენა პროცესზე არ აქვს.

**სპონსორს** უნდა, რომ მისი ბრენდი ტურნირის გვერდზე ჩანდეს. სპონსორობის პირობებზე ორგანიზატორთან თანხმდება 

**ადმინისტრატორი** პლატფორმის მფლობელია. ზრუნავს, რომ თაღლითური ორგანიზატორები და ტურნირები არ გამოჩნდეს. აქვს ვეტო: შეუძლია ორგანიზატორის დამტკიცება ან უარყოფა და ტურნირის დაბლოკვა.

**გადახდის პროვაიდერი (მაგ. TBC ან BOG).** პლატფორმის მომხმარებელი არ არის, მაგრამ მისი წესები ჩვენზე მოქმედებს. ის გადახდებს ამოწმებს და საეჭვო ოპერაცია შეუძლია დაბლოკოს, ამიტომ ვეტო მასაც აქვს.
